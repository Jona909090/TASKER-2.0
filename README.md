# TASKER 2.0

Odvojen projekt za kontrolu poslovanja.

## Faza 1

Prva pregledna frontend verzija sadrži:
- Tasker vizualni stil
- strukturu modula po uzoru na iSKAP
- Nadzornu ploču
- Gradilišta
- Zaposlenike i kompletne glavne tabove zaposlenika
- klikabilan lijevi meni
- demo tablice za ostale module

## Način rada

Svaka faza mora ostati pregledna prije nego krenemo dalje. Nakon završene faze provjeravamo izgled i funkcionalnost, pa tek nakon odobrenja prelazimo na sljedeću.

Podaci u ovoj fazi su isključivo demo podaci. Backend i prava baza još nisu spojeni.
